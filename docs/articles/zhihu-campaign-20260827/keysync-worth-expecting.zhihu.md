# DeepSeek 的 Harness 值得期待吗？

值得，但不要把期待放错地方。

如果期待它一出来就像 Codex 一样，下载安装、登录账号、直接开始干活，那目前还不是。DSH 的第一版更像一个开放的工作台：能加能力，能换工具，也能按自己的习惯改，但安装和日常使用仍然偏开发者。

我真正期待的是另一件事：它能不能逐渐变成一个长期使用的工作入口。

对我来说，好用不是某次演示里写代码多快，而是这几个问题有没有解决：

- 每天打开时，还要不要找命令、找端口；
- 做到一半的任务，第二天能不能接着做；
- DSH 做不好的任务，能不能直接换 Codex 或 Claude；
- 人离开电脑以后，能不能从手机继续看进度、补一句要求。

DSH 现在已经证明了它的开放性，但离普通人每天使用，还差一个更简单的入口。

这也是我做 KeySync 的原因。它把 DSH 变成更接近普通桌面软件的使用方式：不用单独安装 Node，不用输入命令，macOS、Windows、Linux 都可以一键安装；安装后在客户端里用按钮启动、停止和打开。

![KeySync 客户端中的 DSH](/Users/boboyang/work/Relay/docs/articles/zhihu-campaign-20260827/assets/keysync-dsh-desktop/keysync-client-dsh-running-stop-open.png)

如果任务跑得久，人已经离开电脑，也可以从手机回到原来的 DSH 会话。不是重新开一个聊天，项目和任务仍然在原来的电脑上。

![手机继续办公室电脑上的 DSH](/Users/boboyang/work/Relay/docs/articles/zhihu-campaign-20260827/assets/keysync-dsh-desktop/phone-b12-05-1-dsh-opened.png)

所以我的答案是：DSH 值得期待，但它最有希望的方向不是“再做一个国产 Codex”，而是成为一个可以接入不同 Agent、插件和工作方式的长期工作台。

如果你只是偶尔让 AI 写几段代码，现在成熟工具更省事；如果你希望自己决定用什么模型、装什么能力，并且让长任务可以跨设备继续，DSH 就很值得关注。
