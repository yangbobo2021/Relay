## Style Checks Applied

- Each answer has one primary reader scenario.
- Technical names are introduced only after the reader pain point is clear.
- Product mentions are tied to concrete situations: plugin discovery, Codex
  continuity, Claude review, in-app file/terminal work, and multi-device relay.
- Each draft uses 1-3 local media references; avoid overloading a Zhihu answer
  with too many screenshots.
- Related links are grouped at the end so the answer does not open like an ad.
