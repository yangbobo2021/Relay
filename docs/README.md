# Relay Documentation

- [Specification](spec/README.md) defines required product and runtime behavior.
- [Design](design/README.md) maps the specification to the first implementation.
- [Acceptance](acceptance/README.md) traces requirements to executable scenarios and
  records release evidence.
- [Architecture](architecture.md) describes component boundaries and data flow.
- [Decisions](decisions.md) records why consequential choices were made.
- [DSH Plugin Catalog](dsh-plugins.md) is the user-facing entry point for the
  independently installable Codex, Claude Code, Workbench, Files, and Terminal
  plugins ([中文](dsh-plugins.zh.md)).

Research and compatibility notes that are specific to DeepSeek Harness belong in
[`dsh-lab/`](../dsh-lab/README.md), not in the product specification.
