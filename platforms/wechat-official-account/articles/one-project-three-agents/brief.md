- 主题：把 DSH、Codex 和 Claude Code 按项目组织，而不是按应用寻找聊天记录

- 文章类型：工作流实践，兼具工具软推广
- 读者收获：一套可手动执行的“讨论、实现、审查”分工方式，以及现阶段真实能力边界
- 证据：官方 DSH 模式选择、Codex Thread 导入、Codex 对话旁 Files 视图
