# 选题简报

## 选题

把跨平台教程《小白 3 步上手 DeepSeek Harness：一键安装，手机接着用》改写为适合微信公众号阅读和收藏的入门教程。

## 目标读者

- 想试 DeepSeek Harness，但害怕安装环境、终端和命令的普通用户。
- 没有编程基础，希望照着截图完成安装的人。
- 已经在电脑上使用 AI 工具，希望离开电脑后用手机继续原任务的人。

## 读者问题

1. 不知道安装 DeepSeek Harness 是否需要 Node、终端和命令。
2. 不清楚如何填写 DeepSeek 模型服务。
3. 不知道手机如何打开电脑上的同一个 DSH，也担心必须连接同一 Wi-Fi。

## 文章承诺

读者按三个大步骤完成：

1. 安装 KeySync。
2. 在 KeySync 中一键安装、配置并打开 DeepSeek Harness。
3. 用手机浏览器远程打开电脑上的同一个 DeepSeek Harness。

## 文章类型

- Primary：新手实操教程。
- Secondary：工具软推广、跨平台改写。

## 必须保持的事实

- KeySync 支持 macOS、Windows、Linux。
- 用户不用另外安装 Node，也不用敲命令。
- KeySync 客户端和远程访问目前完全免费，没有隐藏收费。
- KeySync 是第三方产品，不是 DeepSeek Harness 官方客户端，也不是开源项目。
- DeepSeek Harness 打开时，以 KeySync Client 出现“停止”按钮作为判断标准，不写成页面“显示运行中”。
- 手机和电脑不需要同一 Wi-Fi。
- 电脑必须开机、联网，KeySync 正在运行。
- 任务仍在电脑上处理，手机只是远程打开并继续使用。

## 内容结构

1. 第一屏：先消除“装环境、开终端、敲命令”的顾虑。
2. 开始前准备：电脑、KeySync 账号、DeepSeek API Key。
3. 第一步：安装 KeySync。
4. 第二步：安装、配置并打开 DSH。
5. 第三步：手机远程打开电脑上的 DSH。
6. 常见问题：电脑离线、没有远程打开、模型测试失败。
7. 产品边界与相关链接。
